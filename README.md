# 🌍 Samuel Jiménez López — Portfolio

Portfolio personal donde combino **desarrollo de software** y **patinaje artístico**, mostrando proyectos, experiencia y una iniciativa propia: **Axels Around The World**.

---

## 🚀 Sobre el proyecto

Este portfolio está diseñado como una web moderna e interactiva donde se puede:

- Explorar mis proyectos de desarrollo  
- Conocer mi trayectoria deportiva  
- Visualizar contenido dinámico de viajes y patinaje  
- Navegar por una experiencia cuidada a nivel de **UI/UX**

👉 El objetivo es reflejar un perfil completo: **tecnología + alto rendimiento deportivo**

---

## 🌍 Axels Around The World

Una de las secciones principales del portfolio.

Consiste en realizar el salto **Axel** en distintos lugares emblemáticos del mundo, creando una colección visual y geográfica única.

- 📍 Cada salto está asociado a una ubicación real  
- 🎥 Integración de vídeos  
- 🗺️ Visualización en mapa interactivo  

---

## 🛠️ Tecnologías

El proyecto está desarrollado con:

- **React**  
- **Vite**  
- **JavaScript (ES6+)**  
- **CSS moderno / UI personalizada**  

---

