## Sobre el proyecto

[![Portfolio Screen Shot][product-screenshot]][demo-url]

Este proyecto es un portfolio desarrollado con React y Vite para presentar el perfil mixto de Samuel Jiménez: desarrollo de software y patinaje artístico. La web combina una portada con vídeo, una sección de presentación personal, un selector de identidad entre Developer y Skater, y una galería de proyectos destacados.

Objetivos principales:

* Mostrar proyectos propios como Axion, EMT Palma Real-Time App y Murdoch: Beacon of Shadows.
* Comunicar una identidad profesional basada en disciplina, aprendizaje rápido y mentalidad competitiva.
* Servir como sitio personal desplegable en GitHub Pages.
* Mantener una base sencilla para iterar nuevas secciones, enlaces de contacto y contenido del CV.

<!-- GETTING STARTED -->
## Primeros pasos

Sigue estos pasos para ejecutar el proyecto en local.

### Requisitos

Necesitas tener instalado:

* Node.js 20 o superior
* npm

Puedes comprobar tus versiones con:

```sh
node --version
npm --version
```

### Instalación

1. Clona el repositorio.
   ```sh
   git clone https://github.com/Samusk8/Portfolio.git
   ```
2. Entra en la carpeta de la aplicación.
   ```sh
   cd Portfolio/portfolio
   ```
3. Instala las dependencias.
   ```sh
   npm install
   ```
4. Arranca el servidor de desarrollo.
   ```sh
   npm run dev
   ```
5. Abre la URL local que indique Vite en la terminal.

<!-- USAGE EXAMPLES -->
## Uso

Comandos disponibles:

| Comando | Descripción |
| --- | --- |
| `npm run dev` | Inicia el servidor de desarrollo con Vite. |
| `npm run build` | Genera la versión de producción en `dist`. |
| `npm run preview` | Sirve localmente la build de producción. |
| `npm run lint` | Ejecuta ESLint sobre el proyecto. |
| `npm run deploy` | Publica la carpeta `dist` usando `gh-pages`. |

Para desplegar una nueva versión en GitHub Pages:

```sh
npm run build
npm run deploy
```
